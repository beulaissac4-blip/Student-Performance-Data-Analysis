# Student Performance Data Analysis Using Python

## Project Description
This project is a Python-based Data Analysis Application used to analyze student performance, clean datasets, visualize data, and fetch information from REST APIs.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Requests

## Project Features
1. Dataset Loading using Pandas.
2. Data Cleaning and Missing Value Handling.
3. Student Marks Analysis.
4. Data Visualization using Matplotlib and Seaborn.
5. REST API Integration using HTTP Requests.
6. Automatic Report Generation.

## Project Files
- main.py
- data_cleaning.py
- analysis.py
- visualization.py
- api_data.py
- students.csv
- README.md

## Generated Outputs
- cleaned_students.csv
- api_data.csv
- subject_average.png
- student_performance.png
- analysis_report.txt

## How to Run
1. Install required libraries.
2. Open the project folder in VS Code.
3. Run the following command:

`python main.py`
